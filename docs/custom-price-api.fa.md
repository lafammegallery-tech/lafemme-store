# منبع اختصاصی قیمت

در `.env` سرور (نه در گیت) تنظیم کنید:

```dotenv
MARKET_PRICE_API_URL=https://arbitrage.aectest.ir/simulation/api/public/v1/prices
MARKET_PRICE_API_KEY=YOUR_PRIVATE_KEY
```

کلید به هدر `X-API-Key` فقط از سمت سرور اضافه می‌شود. پس از تغییر تنظیمات، کانتینر برنامه باید دوباره ایجاد شود. انتشار را طبق `security-deployment.fa.md` و پس از پشتیبان‌گیری انجام دهید.

- طلا: `GOLD_18K.buy_price`، مظنه به ریال. قیمت هر گرم ۷۵۰ به تومان = مبلغ ÷ ۴٫۳۳۱۸ ÷ ۱۰. سرویس بازار موجود سپس فقط یک بار آن را × ۹۹۵ ÷ ۷۵۰ می‌کند؛ گرد کردن در انتهای تبدیل عیار انجام می‌شود.
- نقره: `SILVER_1000G_NADIR.buy_price`، شمش ۱۰۰۰ گرمی به ریال. قیمت هر گرم به تومان = مبلغ ÷ ۱۰۰۰ ÷ ۱۰. مطابق تنظیم فعلی فروشگاه این قیمت به عنوان مبنای نقره ۹۹۹ استفاده می‌شود.
- `sell_price`، `buy_price_gram`، آبشده پس‌فردا و شمش امارات استفاده نمی‌شوند.
- پاسخ سالم ۶۰ ثانیه در حافظه هر فرایند نگه داشته می‌شود؛ درخواست‌های هم‌زمان طلا و نقره مشترک هستند.
- قیمت ناموجود، غیرمثبت، تکراری، با واحد نامعتبر یا قدیمی‌تر از ۱۵ دقیقه فقط برای همان فلز رد می‌شود؛ اعتبارسنجی طلا و نقره مستقل است و قطع یکی مانع نمایش و خرید دیگری نیست. پاسخ ناقص نیز ۶۰ ثانیه cache می‌شود و قیمت فلز قطع‌شده از cache قدیمی معتبر تلقی نمی‌شود. این حد فعلاً ثابت است؛ برای تعطیلی بازار نیاز به سیاست جداگانه دارد.
- API درصد تغییر روزانه ندارد؛ مقدار `change24h` فعلاً صفر است، نه تغییر واقعی محاسبه‌شده.
- حالت دستی پنل همچنان برقرار است. قیمت ذخیره‌شده یا قیمت ثابت محصول هنگام قطعی API مجوز ثبت سفارش نیست؛ checkout سمت سرور خرید را تا دریافت قیمت معتبر یا تعیین قیمت دستی متوقف می‌کند. رکوردهای قدیمی قیمت با تعویض منبع حذف نمی‌شوند.
- نشانی فعلی شامل `/simulation/` است؛ پیش از استفاده برای فروش واقعی تأیید کنید این همان منبع موردنظر است.

کلیدی که در چت ارسال شده را پیش از انتشار تعویض کنید. کلید واقعی نباید در فایل مثال، کد، لاگ یا تنظیمات عمومی `NEXT_PUBLIC_*` قرار بگیرد.
