# راهنمای پیشنهاد خرید بر اساس بودجه

- فقط در شاخهٔ `feat/investment-calculator-preview` توسعه داده شده؛ انتشار روی production نیاز به تأیید جداگانه دارد.
- صفحهٔ اصلی: بعد از نمای بازار، قبل از محصولات منتخب. سه حالت «فقط طلا»، «فقط نقره»، «طلا و نقره».
- API خواندنی `POST /api/investment-planner` با `budget` (تومان صحیح) و `mode` (`gold`, `silver`, `mixed`). هیچ سفارش یا رزروی ایجاد نمی‌کند.
- فقط محصولات فعال واقعی با موجودی قابل رزرو، وزن مثبت و قیمت معتبر فعلی (API یا دستی) قابل پیشنهادند. داده‌های نمایشی و قیمت fallback کنار گذاشته می‌شوند.
- جست‌وجوی محدود و قطعی با بسته‌بندی دودویی موجودی و نگه‌داری گزینه‌های برتر و ارزان‌تر، تا سه ترکیب متمایز می‌سازد. تضمین بهینهٔ سراسری ندارد و این محدودیت در رابط اعلام می‌شود.
- معیارها: وزن فلز، استفاده از بودجه، و ترکیب جایگزین با امکان چند قطعه. در حالت mixed همهٔ معیارها ابتدا وزن طلا را ترجیح می‌دهند؛ این اولویت در عنوان و توضیح مشتری اعلام نمی‌شود.
- وزن طلا و نقره جداگانه گزارش می‌شود؛ وزن محصول است، نه وزن خالص تعدیل‌شده بر اساس عیار. هزینهٔ ارسال در پیشنهاد نیست و قیمت نهایی هنگام خرید دوباره کنترل می‌شود.
- اگر هر دو فلز در بودجه جای نگیرند، حالت mixed می‌تواند تک‌فلزی پیشنهاد بدهد و این را توضیح می‌دهد. قیمت نامعتبر/موجودی خالی/بودجهٔ کم/خطای شبکه حالت مشخص دارند.
- توضیحات بر اساس ترکیب واقعی‌اند، بدون پیش‌بینی بازار یا وعدهٔ سود. UI از حالت روشن، RTL، موبایل، صفحه‌کلید و reduced-motion پیروی می‌کند.
- تست: `npm test`، `npm run check` و `npm run build`. برای بررسی دستی، هر سه فلز، ارقام فارسی/عربی، بودجه کم، تغییر ورودی پس از محاسبه و لینک محصول را آزمایش کنید.
