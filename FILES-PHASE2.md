# Phase 2 Created Files

- `src/ui/index.ts`: single public export surface.
- `src/ui/tokens/index.ts`: typed colors, typography, spacing, radius, shadows, and animation values.
- `src/ui/utilities.css`: Tailwind animation, focus, scrollbar, and reduced-motion utilities.
- `src/ui/utils/cn.ts`: conditional class-name helper.
- `src/ui/layout/*`: generic layout composition components with no route data.
- `src/ui/primitives/*`: foundational presentation and action primitives.
- `src/ui/forms/*`: accessible native-form wrappers and controls.
- `src/ui/overlay/*`: client-side Modal, Dialog, and Drawer primitives.
- `src/ui/feedback/*`: loading-independent empty, error, and toast feedback.
- `src/ui/navigation/*`: breadcrumb, tabs, accordion, and pagination controls.
- `src/ui/commerce/ProductCard.tsx`: reusable product presentation only.
- `src/ui/icons/*`: shared SVG icon foundation and initial icon set.
- `DESIGN-SYSTEM.md`: component tree and scope statement.
